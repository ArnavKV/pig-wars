# Pig Wars

A collaborative browser game built using HTML, CSS, and JavaScript.

## Project status

This is recovered source code from an earlier collaborative project. The current build has **not yet been tested**.

## Running locally

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. If assets or browser restrictions prevent the game from working, further setup or fixes may be needed.

## Technologies

- HTML
- CSS
- JavaScript
